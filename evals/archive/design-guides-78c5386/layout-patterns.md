# 布局边界

仅检查当前改动涉及的项，不把它们扩成整页改造清单。

- **结果与导航**：完整目录、标签与筛选可能重复占据空间。调整组织后仍保留全部入口；展开过程应允许连续选择，收起后能辨认当前条件。
- **条目与动作**：短动作可与身份信息并排，长文允许换行。操作不覆盖主体；状态变化不应让名称或触点跳位。不能只用图标的可访问名称代替可见含义。
- **媒体**：区别元素框和实际图像面积。完整构图不等于主体够大；查看细节时需要明确的还原、退出和可达边缘。保留比例并复查相关文字、动作的可达性。
- **跨尺寸返回**：条件、来源焦点和浏览位置可以恢复，折叠状态必须服从当前布局。不能恢复手机的关闭状态，却在桌面隐藏展开按钮。实际验证窄屏进入→宽屏返回及反向路径，不能只看两个静态截图。

尺寸或拟合读数有疑问时再用[诊断](preview-diagnostics.md)和采集脚本；读数本身不判定页面质量。
