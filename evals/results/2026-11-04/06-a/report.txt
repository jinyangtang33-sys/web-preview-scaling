# page.html 标题过大排查

源码原因明确：`project/page.html:8` 的 `h1 { font-size: 6vw; }` 让标题随视口宽度持续增大，没有设置 48px 上限。

按用户给定的桌面目标视口 **1440 × 900 CSS px** 静态推算，标题字号为 `1440 × 6 / 100 = 86.4px`，超过设计上限 48px 共 **38.4px（80%）**。视口宽度等于 800px 时字号达到 48px；超过 800px 就会超标。高度 900px 不参与 `vw` 的计算，`body` 的 24px 外边距也不会把 `vw` 改为相对于内容宽度计算。

完整页面只有这一条标题字号规则，没有媒体查询、外部样式引用或脚本覆盖。静态证据支持“未限幅的 vw 字号”是桌面标题过大的直接原因。无法据此证明预览宿主、浏览器缩放、实际字体、换行或页面几何的情况。

建议需要修复时将该规则替换为：

```css
h1 { font-size: min(6vw, 48px); }
```

该建议保留宽度不超过 800px 时现有的字号行为，并把较宽视口下的字号限制为 48px。在 1440px 宽度下，公式预测值会由 86.4px 变为 48px。以上是未应用的建议和静态推算，不是修复后的浏览器实测。

本轮按“排查、只能读源码”范围执行，**未修改 `project/page.html`**，未使用浏览器、截图或 Playwright，也没有启动页面服务或提交 Git。
