# 标题过大原因排查

`project/page.html:8` 的 `h1 { font-size: 6vw; }` 是静态检查发现的直接原因：字号随视口宽度增长，没有设计上限。

按用户提供的目标 CSS 视口 **1440 × 900** 推导，`6vw = 1440 × 0.06 = 86.4px`，超过 **48px** 上限 **38.4px（80%）**。视口宽度大于 **800px** 时，该规则就会超过 48px。页面没有其他字号声明、媒体查询、外部样式表或脚本覆盖这条规则。

建议将该规则改为 `h1 { font-size: min(6vw, 48px); }`，保留较窄视口的现有缩放方式，并限制宽屏字号。建议规则在目标视口的理论值为 48px，尚未实施或实测。本轮请求为原因排查，`page.html` 未修改。

以上全部来自源码和公式计算，不是浏览器计算样式或实际渲染读数。没有使用浏览器、截图、Playwright，也没有测量实际预览窗口。**视觉验收待完成**：后续允许浏览器检查时，应验证目标 1440 × 900、实际预览 CSS 视口，以及采用建议规则后的 799px / 800px / 801px 宽度附近；核对实际字号、标题换行与溢出。未声称这些视觉指标已通过。
