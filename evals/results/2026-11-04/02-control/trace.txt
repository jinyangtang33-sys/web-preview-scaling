4. 使用 apply_patch 修改 project/page.html 的两条 CSS 规则。

```diff
-  main { width: calc(100% - 32px); margin: 40px auto; }
-  h1 { font-size: 6vw; line-height: 1.2; }
+  main { width: calc(100% - 32px); max-width: 1040px; margin: 40px auto; }
+  h1 { font-size: clamp(32px, 4vw, 48px); line-height: 1.2; }
```

结果：补丁成功。

5. 执行修复后的验证。


结果：退出码 0。1440 × 900 与 390 × 844 下三类断言均通过。原始读数保存在 evidence.json。
