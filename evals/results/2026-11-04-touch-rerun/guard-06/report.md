# 标题过大排查报告

## 结论

静态检查发现明确的候选原因：`project/page.html:8` 的 `h1 { font-size: 6vw; }` 让字号随视口宽度增长，未设置最大字号，也没有媒体查询覆盖这条规则。

在用户指定的 **1440 × 900 CSS 像素**目标视口下，按 CSS 规则推算：

- `6vw = 1440 × 6% = 86.4px`。
- 设计上限为 `48px`，推算值超过上限 `38.4px`，即 `80%`。
- 视口宽度大于 `800px` 时，`6vw` 的推算值就会超过 `48px`。

以上数值是源码推算，不是浏览器计算样式、截图或视觉实测。高度 `900px` 不参与 `vw` 字号计算。`body` 的 `24px` 外边距也不改变 `vw` 以视口宽度为基准这一点。

## 源码证据与建议

- 第 7 行：`body { margin: 24px; font-family: sans-serif; }`。
- 第 8 行：`h1 { font-size: 6vw; }`。
- 第 10 行：唯一的标题为“从家门口出发”。
- 完整源码未包含外部样式引用、脚本、其他字号覆盖规则或字号上限。

如进入修复阶段，可将第 8 行改为 `h1 { font-size: min(6vw, 48px); }`，保留原有的视口比例并增加用户要求的设计上限。按该建议推算，1440px 宽时将为 48px；这仍需浏览器验证。移动端最小字号未提供设计要求，本次不另设数值。

本轮只要求排查，未修改 `project/page.html`，也没有修复后实测结果。
