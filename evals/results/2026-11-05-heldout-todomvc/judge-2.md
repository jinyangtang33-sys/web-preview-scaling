# 独立匿名视觉评审

结论：A，轻微优势。A 19/24，B 18/24。判断依据是原始 TodoMVC 日常使用任务，不以居中或左对齐的风格偏好决定胜负。

评审范围：仅阅读本目录 request.txt、manifest.json 和 A/B 共 16 张截图；以每张图片的原始 1440×900 或 390×844 尺寸逐张检查。未读取源码、分组、技能、预算或其他评审；未访问黑盒页面。

## 六项评分及可见依据

1. 辨认与扫读：A 3/4，B 3/4。
   - 两版均有清楚的 todos 品牌、18px 左右的任务文字、固定在左侧的圆形完成控件；已完成任务同时用绿色勾选、删除线和浅色行背景区分，未只依赖颜色。
   - 两版的混合状态均能读全中英文任务与长任务，Edit/Delete 在每行持续可见。B 的筛选选中项是实心红底，辨识比 A 的浅红边框更强；A 的筛选在列表前，进入长列表时较早可见。二者都清晰，未出现足以拉开一个等级的扫读障碍。

2. 层级、分组、字号与间距：A 3/4，B 3/4。
   - 两版均以卡片、行分隔线和独立底栏组织新增、任务和汇总，品牌、任务与辅助文字的字号有层次。A 的 New task (required) 提供稳定字段标题；B 省去该行，结构更紧凑。
   - A 将 Complete all 与筛选并排放入同一工具栏，手机上略密；B 将批量完成单独成行，底部筛选独立成组。两版手机第一条任务都因动作换行留出较多空白，但任务与按钮并未重叠。

3. 内容与动作对任务的支持：A 4/4，B 3/4。
   - 两版均直接显示 Add、Edit、Delete、Save、Cancel、筛选与 Clear completed，完成状态与剩余数量可见，未添加偏离任务的仪表盘内容。
   - A 在桌面和手机编辑态都显示 An empty title deletes this task.，在实际编辑位置明确解释可能导致删除的输入结果；新增输入也有始终可见的 New task (required) 标签。这些内容直接支持原任务要求的新增、编辑、取消和删除理解。
   - B 的编辑态有清楚的 Save/Cancel，但没有空标题删除提示；新增区只靠占位文字表达用途。B 的 Mark all complete 比 A 的 Complete all 略明确。截图只证明动作存在与文案可见，不证明工作流已成功执行。

4. 手机连贯与操作：A 3/4，B 3/4。
   - 390×844 下两版卡片都保持屏内宽度，长任务自然换为四行左右，完成控件与 Edit/Delete 没有覆盖文字；编辑框占满可用宽度，Save/Cancel 移到下行，布局连贯。
   - A 的筛选位于任务列表之前，在 mixed 和 editing 截图中仍能直接看到当前 All 选择；B 的筛选位于底部，三项宽且红底选中态强，mixed/editing 中仍在本张截图内可见，但位置随列表长度下移。
   - 两版按钮视觉高度约 44–48px，适合触控的外观；完成圆圈较小，实际可点击区域未知。两版 mixed/editing 的署名均在首屏下方，不能由此判为丢失。没有实际触摸、键盘或滚动验证。

5. 桌面空间与布局：A 3/4，B 3/4。
   - 1440×900 下两版均采用居中的适度宽度单列卡片，任务和操作保持稳定对齐，长任务可完整分行，混合与编辑状态的任务、底栏和署名均在首屏内。
   - A 卡片约 800px 宽，B 约 760px 宽；二者都避免任务行拉得过长。A 左对齐标题与卡片边缘形成一致起点，B 居中标题与卡片形成完整轴线，属于可用的不同布局选择，未按个人偏好加减分。

6. 跨状态一致与克制：A 3/4，B 3/4。
   - 两版在 empty、mixed、active、editing 中均保持同一品牌、配色、卡片和按钮语言，筛选选中态与编辑焦点清楚；都保留作者、维护者和项目署名的可见证据，未见外部装饰或虚构功能。
   - A 空态隐藏无对象可编辑的说明，非空态才提示 Edit/双击，较贴合上下文；B 在空态也显示编辑说明，帮助内容与当下任务略不匹配。两版 mixed 的完成文字仍较深，editing 中则变灰，存在轻微状态样式差异，但完成勾选和删除线始终一致。

## 选择理由

A 的优势较小，集中在任务理解与输入结果解释：稳定字段标签、编辑位置的空标题删除提示，以及在长列表之前出现的筛选。这些可见证据与原始任务的日常使用、理解动作和保留工作流直接相关。B 的筛选更醒目、手机三项导航更宽，批量完成文案也更明确，因此手机与整体清晰度保持同档；没有足够证据将其评为明显落后。

- B：1440-empty、1440-mixed、1440-active、1440-editing、390-empty、390-mixed、390-active、390-editing，全部逐张原尺寸检查。

## 限制

这是静态视觉评审。未验证 add/edit/cancel/complete/filter/delete/clear-all-completed 的运行结果、焦点顺序、屏幕阅读器标签、真实点击命中范围、触摸表现、键盘行为、滚动后内容或内存 Store 语义。未因按钮看起来可用而推断功能通过。未检查截图之外的 Completed 筛选、全完成、校验失败、超长无空格文本或虚拟键盘出现等状态。分数反映所给截图的证据强度，A 的轻微领先不代表功能正确性结论。
